# Netflix Movies and TV Shows Dashboard | Power BI

A Power BI dashboard project using a Netflix titles dataset to explore the catalog of movies and television shows through interactive visual analytics.

## Project Overview

This project uses a Netflix titles CSV dataset and a Power BI dashboard file. The goal is to make the available catalog easier to explore through visual summaries and filters.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (where used in the dashboard)
- CSV data
- Data visualization

## Suggested Analytical Questions

The dataset can support analysis such as:

- How is the catalog distributed between movies and TV shows?
- How do titles vary by release year?
- Which countries contribute titles to the catalog?
- What genres or categories appear most frequently?
- How does the catalog change across time?
- What content information is available for each title?

These are analytical questions the dataset can support; they are not claims about verified dashboard results.

## Analytical Workflow

1. Load the CSV dataset into Power BI.
2. Review column types, missing values and data quality.
3. Prepare the dataset using Power Query.
4. Create measures and calculated fields where required.
5. Develop visual summaries and interactive filters.
6. Validate dashboard totals against the source dataset.
